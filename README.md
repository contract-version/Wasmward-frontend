# Wasmward frontend

This repository is intentionally empty for now.

[Wasmward](https://github.com/contract-version/Wasmward-backend) is a library and CLI, and its specification rules out UI screens and a React package: browser apps use the core `subscribe` API directly. The one planned frontend item is a browser example that uses `guard.subscribe` to disable write buttons, which is on the seed backlog and will live here if it is built.

- Library and CLI: [Wasmward-backend](https://github.com/contract-version/Wasmward-backend)
- Test contract and testnet deploy script: [Wasmward-contract](https://github.com/contract-version/Wasmward-contract)
